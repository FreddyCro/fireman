火熄了

（結語內容待填。）

這版和 ink-edge 差在哪

  1. 從 SVG filter 換成 WebGL shader。ink-edge 的邊緣是一張靜態噪聲把白塊邊界扭曲，不會自己動，所以看起來像燒過後的焦痕。火需要每一幀都在變形，SVG filter 每幀重算 feTurbulence 太重，改用 shader 才跑得動。
  2. 隨機造型來自三層噪聲。往上捲動的 fbm 噪聲決定火焰本體；另一組噪聲拿來扭曲取樣座標（domain warp），讓火舌會捲、會分岔；第三組低頻噪聲沿著水平方向改變每一段的火焰高度，做出高低不一的火舌。
  3. 整頁只有同一團火。火固定在視窗底部，跟 ink-edge 一樣是單一個效果；變的只有火勢。
  4. 火勢是一個 0–1 的數字，隨捲動連續變化。每一段 data-fire 是一個關鍵影格：視窗中心走到兩段之間，火勢就在兩段的值之間內插，再做一點平滑，滾輪一格一格跳時火不會跟著跳。這個數字同時控制火焰高度、竄升速度、最高溫度（黃白 → 橘 → 暗紅）、斷續程度和火星數量。
  5. 火在文字後方。段落拿掉底色、文字加暗色陰影，火從字的後面燒上來；面板可以切到「火在文字前方」比較。

待討論

  1. 火在文字後方還是前方？前方比較有衝擊力，但大火時會蓋住下半部的內文。
  2. 底色要維持全黑，還是隨火勢變小慢慢轉成灰白，呼應「火熄、煙散」？
  3. 手機效能：現在用半解析度渲染。實際上線前要在中低階手機上量 FPS，必要時再降解析度或只在火進入畫面時才畫。
