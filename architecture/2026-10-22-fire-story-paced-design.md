# fire-story-paced：B 版加紐時式節奏（C 版）設計

日期：2026-10-22　接續 [2026-10-19-fire-story-auto-design.md](2026-10-19-fire-story-auto-design.md)

## 目標

設計師希望 4-1、4-3 參考紐時〈An Agoraphobe Goes to the Grocery Store〉：「不綁滾動、觸發播放、效果順暢」。拆解結果見 [scroll-video-transitions.md](scroll-video-transitions.md)。觸發播放 B 版已經做了，跟紐時的差別在**節奏**，所以另開 C 版 `/poc/fire-story-paced` 比較：

| | A `/poc/fire-story` | B `/poc/fire-story-auto` | C `/poc/fire-story-paced` |
|---|---|---|---|
| 4-1、4-3 | 跟著捲動 scrub | 觸發後 1 倍速播放 | 同 B |
| 影片之間 | 硬切 | 硬切 | 硬切 |
| 跑道 | 1800vh | 1800vh | **2200vh** |
| 觸發點上的文字 | — | 說明文字幾乎和 4-1 同時出現 | **沒有文字**，4-1 先在空畫面播 80vh |
| 區 0（4-1 → 4-2 → 名單） | — | 約 190vh | **400vh** |
| 往回捲 | 倒帶 | 顯示播完的狀態 | 同 B |

## C 版做了什麼

只改時間軸，引擎和序列規則不動。

- **C1～C3 手感不變**：跑道變長後進度 `p` 會變，所以 C1～C3 的關鍵幀與文字照 B 版的 **vh 位置**等比換算（`fromBase`），捲同樣的距離看到同樣的畫面。
- **C4 以「T1 之後幾 vh」排**（`afterT1`）：

| T1 之後 | 畫面 | 文字 |
|---|---|---|
| 0 | 4-1 淡入完成，觸發播放（3 秒） | 沒有 |
| 80 → 200 | 4-1 播完接 4-2 loop | 說明文字（受困女子……殉職的消防員） |
| 200 → 400 | 4-2 loop | 殉職名單由下往上捲（4-2 出現後才看得到） |
| 400 | 觸發 4-3（3 秒），硬切蓋掉 4-2 | 沒有 |
| 400 → 600 | 4-3 播完淡到黑底 | 教訓文字在 4-3 播完後原地淡入（時間驅動） |
| 600 → 620 | | 教訓文字跟著捲動退場 |
| 640 → 815 | | 標題「消防員之死」進場、退場 |

## 沒改的

- **往回捲顯示播完的狀態**（紐時是重播）：從黑底往回捲到區 0 時，重播 4-1 會從黑畫面硬切回滿版火，不如直接顯示 4-2。若設計師想試重播，只要改 `sequence.ts` 規則 2。
- **影片之間硬切**：設計師 2026-10-20 的要求。硬切要順，靠的是素材頭尾畫面對齊（4-1 結尾 = 4-2 開頭、4-2 loop = 4-3 開頭），要請動畫師確認，見 [scroll-video-transitions.md](scroll-video-transitions.md) 的交件規格。

## 取捨

- 總長多 400vh，跟「滾動起來要滑比較久」的回饋方向相反；多出來的都在 C4。設計師比較後若 C 版節奏較好，可以再一起收 C1～C3。
- 400vh 是照紐時的比例抓的（6 秒影片配約 360vh）。我們的 4-1 只有 3 秒，可以再收，但說明文字和名單也需要閱讀距離。

## 驗證

- `pnpm test`（`test/poc-fire-story-paced.spec.ts`）：C1～C3 換算成 vh 與 B 版一致、觸發點沒有文字、區 0 ≥ 360vh、名單接在說明文字後面、教訓文字在 T3 後 ≥ 200vh 才退場、序列沿用 B 版。
- `pnpm generate`：三頁都有輸出。
- 實際手感由使用者在瀏覽器確認。
