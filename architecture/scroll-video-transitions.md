# 捲動觸發影片的轉場銜接

背景動畫由影片組成、捲到定點自動播放時，影片之間怎麼接才順。依據是 2026-10-22 拆解 NYT〈An Agoraphobe Goes to the Grocery Store〉（2025-03-14）的實測結果；本專案對應的實作是 [fire-story B 版](2026-10-19-fire-story-auto-design.md)。

## 結論

> 每一段的頭尾要跟前後段接得上，而且每個接點都要有一個可以一直停著的畫面。

像剪片時素材前後留轉場空間，但更精確地說是兩件事：

1. **接點畫面一致**：每支影片的第一格 = 上一支的最後一格。銜接順是因為畫面本來就對得上，淡化只是遮接縫。
2. **停留狀態**：使用者可能停在任何地方，每個接點都要有能無限停留的畫面（loop 片，或播完停在最後一格）。時間上的餘裕由**捲動長度**提供，不是靠影片。

## NYT 怎麼做

架構是 `@sveltejs/svelte-scroller`：sticky 背景層 + 前景一段段 `<section>`，每個 section 對應背景的一個 item（一支影片）。

| section | 影片 | 內容 |
|---|---|---|
| "safe spaces" | 0.25 秒 loop | 白底人物原地抖動（停留狀態） |
| "early 20s"、"I also didn't eat much" | 6 秒，不 loop | 白底 → 背景轉藍灰 → 人物散成色塊 → 深藍（轉場片） |
| "I was fortunate" | 10 秒，不 loop | 深藍開頭 → … → 白底（下一支轉場片） |

實測行為：

- **觸發**：section 頂端捲到畫面 50% 時切換，新 item 以 `opacity` 0.5 秒交叉淡化進場，影片從 `t=0` `play()`。
- **不快轉、不 scrub**：全程 1 倍速，沒有設定 `playbackRate`；慢慢捲或直接跳進來都一樣播滿 6 秒。
- **播完**：`ended` 後把 `currentTime` 設成片長並 `pause()`，停在最後一格。
- **提早離開**：停在當下那格跟著淡出，淡出完（約 600ms）才歸 0。
- **往回捲**：從 0 重播。

### 為什麼慢慢捲、停著不動都順

- **頭尾相接**：0.25 秒 loop 的畫面 ≈ 6 秒轉場片的第 0 格；轉場片最後一格的深藍 = 下一支的第 0 格。
- **觸發點落在沒有文字的空檔**：切換那一刻，上一段文字已離開畫面頂端，下一段文字才到畫面底部。所以捲過觸發點就停手，背景也會自己從白播到深藍，看起來像「播完自動銜接」。
- **段落比影片長**：這個 section 約 2610px（3.6 個畫面高），只放三個文字框，照一般閱讀速度在 6 秒內捲不出去。
- **文字放在不透明文字框**：任何背景階段都讀得到，不必等影片播完。
- **捲很快直接越過**：停在中間那格，淡出到下一支的深藍開頭，約 0.5 秒溶接，不會跳一下。

## 交件規格（給動畫師）

| 類型 | 要求 |
|---|---|
| 轉場片 | 開頭 = 前一個停留畫面，結尾 = 下一個停留畫面 |
| loop 片 | 頭尾相同，可以無縫循環 |
| 結尾 | 多留約 0.5 秒靜止（剪接說的 handle），停格或淡化時不會卡在動作中間 |

**硬切時更要對齊**：fire-story 依設計師回饋影片之間不淡化（`sequence.fade = 0`），沒有淡化遮接縫，接點畫面不一致會直接跳一下。

## 套到 fire-story

| 接點 | 要求 |
|---|---|
| 3-6 → 4-1 | 4-1 第一格 ≈ 3-6（目前用關鍵幀淡入 0.72→0.75 遮接縫） |
| 4-1 → 4-2 | 4-1 最後一格 = 4-2 第一格（硬切） |
| 4-2 → 4-3 | 4-2 loop 任一格都可能是接點，所以 4-2 的畫面要穩定，4-3 第一格要對得上 4-2 |
| 4-3 → 黑底 | 4-3 最後一格接近全黑（目前淡到黑底遮接縫） |

排版上可借鏡 NYT：

- **觸發點和文字錯開**：讓轉場在沒有字的空檔開始。
- **區段長度大於影片長度**：B 版區 0 目前約 200vh，NYT 同類段落約 360vh；收短跑道時要守住這條。
- **往回捲的行為**：NYT 重播；B 版直接顯示播完狀態（`sequence.ts` 規則 2）。要改成重播只需改這條規則。
