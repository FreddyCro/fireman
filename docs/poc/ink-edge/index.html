拆解 #ink-edge

白色方塊本身是筆直的矩形。之所以看起來像墨水暈開、像火線燒過，是因為整層被套了一串 SVG filter —— 而「位移一塊純色實心矩形」時，只有邊界會顯現出來。

  1. feTurbulence · fractalNoisebaseFrequency 0.015 / 0.02，週期約 50–66px，所以是大塊雲狀噪聲而不是細沙。它決定邊緣起伏的尺度。
  2. feDisplacementMap · scale 220用噪聲 R 通道推 x、G 通道推 y，位移量 ±110px。純色內部推來推去看不出差別，只有邊界被扭曲 —— 這是整個效果的核心。
  3. feGaussianBlur 1.8 + feFuncA discrete先模糊成漸層，再用 alpha 閾值切成 0 或 1。柔邊被「切」成硬邊；脫離主體的白色孤島與黑色孔洞，就是這一步產生的。
  4. feGaussianBlur 0.4只是給那條硬邊補抗鋸齒，不然會有階梯感。

每一步長什麼樣

幾個踩得到的坑

1. 被 filter 的必須是單一純色實心區塊，不然裡面的內容也會一起被扭爛。

2. 容器要外擴大於位移量（這裡 300px > 110px），再由外層 overflow:hidden 裁切，否則兩側會露出直線切口 —— 把控制面板的「關閉外擴」打開就看得到。

3. blur → discrete 的順序不能顛倒：只有 blur 得到霧邊，只有 displacement 得到平滑波浪邊，兩者相疊才是硬質的墨痕。

4. 噪聲場固定在 filter region 座標上，白塊上緣往上掃過這片靜態噪聲，所以邊緣形狀會隨高度不斷變形，而不是一個固定形狀往上平移。

5. SVG filter 每幀重新光柵化整個 filter region，成本不低。原站因此加了 will-change:transform、pointer-events:none，並在手機與 prefers-reduced-motion 下整段跳過。

捲動對應

原站用 GSAP ScrollTrigger scrub，start:"top bottom"、end:"top -25%"。這份復刻用原生 scroll + rAF 算出同一條進度，再套上同一個自訂 ease：前 2% 的捲動直接跳到 18%，讓墨線一出現就有可見厚度，之後線性推到滿版。
